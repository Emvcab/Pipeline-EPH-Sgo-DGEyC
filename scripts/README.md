# Scripts auxiliares

Scripts de análisis y tareas auxiliares del proyecto.

Se ejecutan con **Python local** desde la raíz del repositorio y asumen que las dependencias ya fueron instaladas con `python -m pip install -r requirements.txt`. Ningún script instala paquetes por sí mismo.

El notebook de `notebooks/` se conserva como material demostrativo/exploratorio; no reemplaza este flujo operativo.
